# My Cypress Automation sadeq-teste
This project contains automated end-to-end tests built with Cypress for a school assessment website. The tests verify key functionalities, 
ensuring the application works correctly and providing more reliable and efficient software quality.

## Installation
```bash
npm install
```
>**NOTE**
>
> It is necessary to have **NODE** installed

## Running
```bash
#You open the cypress UI
npx cypress open

#Run the automation by command line
npx cypress run
```
